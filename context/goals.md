# North-Star Goal

Replace my former employer income with income I control, **without taking a worse role out of fear**. The employer salary no longer exists, so the denominator below is a target, not a salary.

## North-Star Metric

**% of target monthly income covered by money that is contracted or paid.**

`(X + Y) / T x 100`

- **T: target monthly income = £5,000/month** (set 23 Oct 2026).
- **X: independent income**, split in two so there is a step between "signed" and "in the bank":
  - **X1, contracted:** signed terms or a written, accepted proposal with a start date. Monthly value.
  - **X2, paid:** money received in the month.
  - Pipeline, verbal interest and "agreed in principle" count for **nothing**.
- **Y: new employment**, base salary only, counted only once an offer is signed. Parallel applications are live now; they count only at signature.
- Bonus and benefits excluded.

**Current: X1 = 0, X2 = 0, Y = 0 -> 0% of £5,000.** Flat since baseline (30 Jun 2026). The £2,000 milestone equals 40% of T.

## Size check (the daunting bit)

£2,000/month is not a stretch of one deal type, it is a specific number of specific things:

- 1 retainer at £2,000/month (the Option A shape), **or**
- 2 ad hoc consultancy days a month at the £1,200 rate card (£2,400), **or**
- 3 x 1:1 workshops (£2,250), **or**
- 41 attendees at £49/head.

For scale, priced deals seen so far: £500 (Spott.me, unsigned), £750 (ThriveWell, lost), £3k est. (MoorConsultations, active), £10k est. (Wisden, lost). **One signed MoorConsultations-sized deal hits the milestone. Nothing else on the list does alone.** T is £5,000, so the milestone is 40% of the way. Reaching T needs, for example, a £2,000 retainer plus two more of the options above.

Rule: each weekly retro scores bets by monthly contracted value, not by conversation count.

## Key driver metric

Weekly pipeline movement, **read from Notion** ("The Pipeline: Live Conversations"). This file defines the stages; Notion holds the data. No pipeline file is kept in the vault.

| Retro bucket | Notion Stage |
|---|---|
| ACTIVE | Active discussion, Interview / process |
| PENDING | Awaiting response, **only** where priced terms, a proposal or an offer is out |
| WARM (not counted) | Initial conversation |
| PARKED | On hold |
| CLOSED | Closed: Won (converts to X1) / Closed: Lost |

Headline number = **like-for-like count** (a paid ask, terms or a role is on the table), plus **Est. value** summed. Est. value must be filled on any row at PENDING or above; an empty value is a data gap, not a zero.

Track movement week to week. A pipeline that is busy but never moves PENDING -> Closed: Won is the pattern to name.
